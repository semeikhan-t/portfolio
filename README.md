# Temirlan Semeikhan — Portfolio

Personal portfolio website with Russian and English content, project details, certificates, and animations.

## Run locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser. No build step or dependencies are required.

## Files

- `index.html` — page structure and content
- `style.css` — responsive styles
- `app.js` — language switcher, project filters, and dialogs
- `motion.js` — scroll animations and hero orbit controls
- `assets/logos/` — certificate issuer logos
- `temirlan-semeikhan-resume.pdf` — downloadable resume

Fonts load from Google Fonts. The page uses system font fallbacks if they are unavailable.
